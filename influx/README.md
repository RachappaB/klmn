# Influx Module

This directory contains the **InfluxDB-based data ingestion, storage, and analysis components** of the project.  
It is designed for working with IoT data, GPS data, and time-series analytics using Python and InfluxDB.

---

## Folder Structure

```text
influx/
├── IOT/                    # IoT-related scripts and experiments
├── gps/                    # GPS data handling and processing
├── data/                   # Local data (ignored by git)
├── .ipynb_checkpoints/     # Jupyter checkpoints (ignored)
├── venv/                   # Python virtual environment (ignored)
├── README.md               # This documentation
├── requirements.txt        # Python dependencies
└── .gitignore              # Git ignore rules for this module
